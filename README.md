 Image Processing Lab

This project is a collection of image processing programs implemented using **Python and OpenCV**. It covers various fundamental image processing techniques, starting from basic image operations and transformations to enhancement, filtering, restoration, compression, morphological operations, and object detection.

📌 Practicals Included

1. **Python & Development Environment Setup**
   - NumPy, Pandas, Matplotlib, Scikit-learn and OpenCV

2. **Image Operations**
   - RGB and Grayscale conversion
   - Arithmetic operations
   - Bitwise operations

3. **Geometric Transformations**
   - Translation
   - Rotation
   - Scaling
   - Shearing
   - Reflection
   - Cropping

4. **Image Enhancement**
   - Histogram Equalization
   - Smoothing
   - Sharpening
   - Thresholding

5. **Spatial Domain Filtering**
   - Averaging Filter
   - Gaussian Filter
   - Median Filter
   - Bilateral Filter

6. **Image Restoration**
   - Telea Inpainting
   - Navier-Stokes Inpainting

7. **Lossless Image Compression**
   - Huffman Coding
   - Original and compressed file size comparison

8. **Morphological Operations**
   - Erosion
   - Dilation
   - Opening
   - Closing

9. **Object Detection**
   - Correlation-based Template Matching

🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Matplotlib
- Pandas
- Scikit-learn

🎯 Objective

The main objective of this project is to understand and implement different image processing techniques using Python and OpenCV and observe their effects on digital images.
